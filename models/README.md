# VeloPath AI Model Weights

This directory holds the deep learning weights for baseball and softball pitch tracking:
- `ball_trackingv4.pt` (~109 MB, YOLOv11 based detection model)

## Automatic Download
VeloPath AI will **automatically download** these weights on the first run if they are not present.

## Manual Download (Optional)
If you are in an offline or air-gapped environment, you can download the weights directly:
- **URL**: https://data.balldatalab.com/index.php/s/YkGBwbFtsf34ky3/download/ball_tracking_v4-YOLOv11.pt
- Save the file into this folder as: `models/ball_trackingv4.pt`
